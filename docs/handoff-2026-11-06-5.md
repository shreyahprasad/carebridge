## Design changes beyond the approved design (owner told)

- Handoff cross-check against `providers.json` and the Case (invented id, moved address, shrunk distance, tampered
  needs, false fact, raised tier, other case or run → `HandoffError`, trip agent never called).
- Extra grades `drive` (car, ≤25 mi) and `unknown` (no location). `not_realistic`, `unknown` and `drive` picks get no
  benefits or questions; `walk` picks skip fare programs. "Young child" = under 6.
- Trip question codes: `provider_dc_medicaid_enrolled`, `kids_ride_free_medical`, `travel_help`, `child_on_trip`,
  `book_ride_ahead`.
- Nothing was cut.

## Gotchas learned

- Anthropic API is unreachable from the sandbox; live runs go to the owner's terminal with `!`.
- Push with `git push https://github.com/shreyahprasad/carebridge.git <branch>` and `github.com` in `allowed_domains`.
- `run_match` adds `path` to its result when it writes a file; strip it before `MatchResult.model_validate`
  (`extra='forbid'`). `run_workflow` does this.
- Privacy tests: check her exact address string ("3100 block"), not a street name a provider may share.
- Project agents in `carebridge/.claude/agents` aren't available when the session starts in `~/projects/personal`.
